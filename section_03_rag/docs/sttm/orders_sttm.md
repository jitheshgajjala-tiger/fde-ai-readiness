# Orders STTM

The gold table gold.orders is loaded from silver.orders_clean every night at 02:00 UTC.
The column order_total is calculated as quantity multiplied by unit_price minus discount_amount.
The column customer_key is a surrogate key generated by hashing customer_id with SHA-256.
Rows with a null order_id are rejected and written to the quarantine table gold.orders_rejects.
Cancelled orders keep their row but order_status is set to CANCELLED and order_total is set to zero.
